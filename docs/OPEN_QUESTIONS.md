# Открытые вопросы

Форматы и решения, которых нет в документах организаторов. По каждому пункту указано, что мы делаем сейчас, пока нет ответа.

## К организаторам

1. **Отметка проверки человеком в `intl_kk_fixed.arb`.** Формат не указан. Сделано: `locqa apply` пишет в `@key` поля `x-reviewed_by_human: true`, `x-reviewed_at`, `x-reviewer` и ведёт `fixed_review.json`. Не проверено, что `flutter gen-l10n` принимает дополнительные поля в метаданных перевода: Flutter на машинах команды пока нет, `locqa validate` запустит его автоматически, если найдёт.
2. **Форма `report.json`.** Дан пример одной находки, форма файла не описана. Сейчас: плоский JSON-массив, сводка в `report_meta.json`.
3. **Дополнительные поля в находке.** Сейчас пишем только 9 полей из примера.
4. **Дубли ключей.** В целевом файле есть повторяющиеся ключи, часть с разными значениями. Считаются ли они ошибкой и какого типа? Сейчас: действует последнее вхождение (как у `json.load` и `flutter gen-l10n`), дубли пишутся в `warnings` в `report_meta.json`. Риск: ошибка, подложенная в раннее вхождение, не будет найдена.
5. **Ключи, которых нет в исходном файле.** Сейчас: предупреждение в `report_meta.json`, не находка.
6. **Язык `evidence`.** Сейчас: русский, как в русской версии описания кейса.

## Внутри команды

7. **`untranslated` для пустых значений.** Сейчас: пустое значение или строка из пробелов считается `untranslated`.
8. **Белый список для `same_as_source`.** Какие ключи и тексты законно совпадают с русским (бренды, имена, служебные символы). Сейчас: пустой список в `config.py`, исключаются строки без букв и латиница при кириллическом исходнике.
9. **Шкала severity по типам.** Сейчас: `untranslated` high; `placeholder_mismatch` high для плейсхолдеров, medium для тегов, low для переносов строк; `same_as_source` medium.
10. **Казахские значения в глоссарии.** Колонку `kk` в `glossary/glossary.csv` заполнили черновиком по частотам из данных. Строки с пометкой «РЕШИТЬ НОСИТЕЛЮ» содержат несколько вариантов через `|` (награда, приз, ставка, сезон, скин, автомобиль, предмет, лидерборд): носитель выбирает один, остальные уходят в `forbidden_kk`. Пока вариантов несколько, `glossary_violation` по этим терминам ловит только переводы мимо всех вариантов. Для «мут» и «выговор» нужен вариант носителя.
11. **Эталон в `inconsistent_term`.** Эталоном считается перевод большинства ключей с тем же исходником. Большинство не всегда право: «Отмена» в 5 ключах переведена как «БАСТАУ» («начать»), и правильные «Болдырмау» помечаются, а в `suggestion` попадает неверный эталон. Носитель должен смотреть `suggestion` этого типа особенно внимательно.
12. **`length_overflow`, нижний ярус.** Ключи-кнопки, вкладки и заголовки с переводом в 2.0–2.5 раза длиннее остаются в отчёте с severity `low` (решили 2026-10-30). Отсекаются флагом `--min-severity medium`.
